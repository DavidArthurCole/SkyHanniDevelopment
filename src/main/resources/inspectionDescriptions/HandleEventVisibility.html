Reports @HandleEvent functions that are not declared private.

Event handlers are invoked by the SkyHanni event bus through the module registry, never called directly, so they should not widen the module's public surface. Overrides are exempt because their visibility is fixed by the parent declaration. 


  @HandleEvent
  fun onSomething(event: SkyHanniEvent) { }

  @HandleEvent
  private fun onSomething(event: SkyHanniEvent) { }

A quick fix adds the private modifier.
